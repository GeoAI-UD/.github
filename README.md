# GeoAI Universidad Distrital Francisco José de Caldas
Laboratorio de Inteligencia Artificial Geospacial con tecnologías de software libre y de código abierto.

Un espacio académico y de investigación orientado al desarrollo de modelos, aplicaciones y sistemas soportados por GeoAI. También realizamos investigación aplicada y procesos educativos asociados al uso, promoción, desarrollo, apropiación y comprensión de los conceptos, tecnologías y herramientas de inteligencia artificial geoespacial (GeoAI).

## Algunos de nuestros proyectos
* Detección de elementos de Fachadas
* Detección de expansión urbana
* Clasificación de uso de suelo a partir de imágenes satelitales
* Identificación de islas de calor en entornos urbanos
* Creación de conjuntos de datos (datasets) de coberturas.
* Definición de contextos LoRA para chatbots sobre LADM-COL y Catastro multipropósito
* Detección de anomalías en conjuntos de datos de avalúos
* Y muchos más....
